# 智安領航站

兩個分頁：

- **資訊新聞**：每天整理重要的 AI 與資安新聞，分國內、國外，每則先列出可點選的來源；Top 5 加 more 展開全部，可依日期區間、關鍵字、類別篩選。資料檔 `data/news.json`，每天早上 8:00 由排程更新。
- **資訊課程**：彙整 e 等公務園+學習平臺（https://elearn.hrd.gov.tw/）上的 AI 與資安課程，分 AI／資安兩組，可依關鍵字、報名身分篩選與排序。資料檔 `data/courses.json`。

- **最新影片**：每天 8:00 蒐集 YouTube 上最新、受關注的 AI 講座與課程，可在網站內直接播放。資料檔 `data/videos.json`。

網站：https://misforest.github.io/ai-security-news/

摘要為改寫整理，請以原始網頁為準；課程認證時數與報名資格以 e 等公務園+ 公告為準。
